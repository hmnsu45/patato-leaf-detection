Potato Disease Classifier - Streamlit website

Run on your computer (Python 3.9 - 3.12):
  pip install -r requirements.txt
  streamlit run app.py
Then open http://localhost:8501

Run on Google Colab:
  upload this zip, then:
  !unzip -q potato-website.zip
  %cd potato-website
  !pip install -q streamlit
  (then start Streamlit and a cloudflared tunnel as explained in chat)
